# 웹 게임 모음

폰과 컴퓨터 브라우저에서 모두 되는 웹 게임들이에요. 로그인 없이 누구나 할 수 있고, 점수는 각자의 브라우저에 기록돼요.

| 게임 | 파일 | 소개 |
| --- | --- | --- |
| 같은 그림 찾기 | `index.html` | 카드를 두 장씩 뒤집어 같은 그림을 찾는 기억력 게임 |
| 은하수 방어선 | `space/index.html` | 13분을 버티며 경험치로 스킬을 키우고, 마지막 모선을 격추하는 우주 슈팅 게임. 스킬 트리와 친구들과 겨루는 전체 순위가 있어요 |

게임마다 파일 하나에 모두 들어 있어요. 설치할 것 없이 브라우저로 열면 바로 시작돼요.

## 같은 그림 찾기

- 난이도: 쉬움(6쌍), 보통(8쌍), 어려움(12쌍)
- 카드를 두 장 뒤집어 같은 그림이면 짝을 찾은 거예요.
- 첫 카드를 뒤집는 순간부터 시간이 흘러요.

| 점수 | |
| --- | --- |
| 짝 맞추기 | +100 |
| 연속 보너스 | 2연속 +50, 3연속 +100, 4연속 +150 … |
| 틀린 시도 | −10 |
| 시간 보너스 | 기준 시간(쉬움 60초 · 보통 90초 · 어려움 150초)에서 남은 1초당 +10 |

난이도마다 최고 점수, 가장 빠른 판, 상위 10개 기록을 볼 수 있어요.

## 은하수 방어선

### 진행

- 지역 5곳(달 궤도 → 소행성대 → 푸른 성운 → 사건의 지평선 → 은하 중심). 앞 지역을 클리어해야 다음 지역이 열려요.
- 13분을 버티면 최종 보스 **모선**이 나타나요. 모선을 격추하면 클리어예요.
- 3:00, 6:30, 10:00에는 중간 보스 **순양함**이 나와요. 순양함은 보급 상자를 꼭 떨어뜨려요.
- 시간이 지날수록 적이 많아지고 단단해지고 총알이 빨라져요. 뒤쪽 지역일수록 더 세요.
- 체력은 바로 보여요. 다 닳으면 작전 실패예요.

### 조작

- 화면 아무 곳이나 누른 채로 끌면 우주선이 따라와요. 공격은 저절로 해요.
- 키보드: 방향키나 WASD로 움직이기, Shift는 천천히, 숫자키로 스킬 고르기, P로 일시정지
- 우주선 가운데 빛나는 점에 맞을 때만 다쳐요.
- 적 총알은 어두운 테두리가 있는 밝은 구슬이라 내 공격이 화려해도 잘 보여요. 그래도 헷갈리면 처음 화면이나 일시정지 화면에서 **내 효과 흐리게**를 고르세요. 내 공격과 폭발이 옅어져요.

### 경험치와 스킬

적을 격추하면 경험치 결정이 떨어져요. 가까이 가거나 결정이 우주선 높이까지 내려오면 저절로 빨려 들어와요.
레벨이 오르면 스킬 3개 중 하나를 골라요. 무기는 5칸, 장비는 5칸이고 각각 Lv 5까지 올라가요.

| 무기 | 하는 일 |
| --- | --- |
| 주포 | 위로 곧게 쏘는 기본 포 |
| 유도 미사일 | 가까운 적을 쫓아가는 미사일 |
| 궤도 드론 | 우주선 둘레를 돌며 부딪치는 적을 때림 |
| 레이저 | 앞을 꿰뚫는 광선을 주기적으로 쏨 |
| 충격파 | 주변 적을 밀어내고 적 총알을 지움 |
| 번개 | 무작위 적에게 떨어져 옆 적으로 번짐 |
| 역장 | 우주선 둘레의 역장이 닿는 적에게 계속 피해를 주고 살짝 밀어냄 |

| 장비 | 효과(레벨마다) |
| --- | --- |
| 강화 장갑 | 최대 체력 +20 |
| 나노 수리 | 초당 체력 0.4 회복 |
| 냉각 장치 | 재사용 시간 −7% |
| 증폭기 | 모든 피해 +10% |
| 확산기 | 범위와 크기 +10% |
| 견인 빔 | 경험치를 끌어오는 거리 +35% |
| 행운 부적 | 아이템이 나올 확률 +20% |
| 흡수 장치 | 적을 격추할 때마다 체력 0.08 회복 |

### 스킬 합체

무기를 Lv 5까지 올리고 짝이 되는 장비를 가진 채 **보급 상자**를 열면 더 강한 스킬로 합체돼요.
무기 칸이 5개라 한 판에 합체 스킬을 최대 5개까지 가질 수 있어요(같은 합체 스킬은 하나씩만).

| 재료 | 합체 스킬 |
| --- | --- |
| 주포 Lv 5 + 증폭기 | 플라즈마 포: 꿰뚫는 플라즈마를 7발씩 쏴요 |
| 유도 미사일 Lv 5 + 냉각 장치 | 벌떼 미사일: 유도 미사일 6발을 쉴 새 없이 쏴요 |
| 궤도 드론 Lv 5 + 강화 장갑 | 수호 위성: 큰 위성 6개가 돌며 총알까지 막아요 |
| 레이저 Lv 5 + 확산기 | 은하 절단기: 굵은 광선이 좌우로 훑어요 |
| 충격파 Lv 5 + 나노 수리 | 생명 파동: 맞힌 적만큼 체력을 회복해요 |
| 번개 Lv 5 + 견인 빔 | 폭풍 핵: 번개가 쉬지 않고 쏟아져요 |
| 역장 Lv 5 + 흡수 장치 | 흡수 역장: 커다란 역장이 적을 녹이며 체력을 흡수하고, 안에 들어온 적 총알을 느리게 해요 |

레벨 업 화면과 일시정지 화면에서 합체 레시피와 지금 진행 상황(예: 주포 Lv 3/5 + 증폭기 ✓)을 볼 수 있어요.
레벨 업 카드와 관련된 레시피는 강조돼요. 레벨 업 화면에는 이번 판과 관련된 레시피만 나오고, **레시피 모두 보기**로 나머지도 볼 수 있어요.

### 적

| 적 | 특징 |
| --- | --- |
| 정찰기 | 기본 적. 여러 편대로 날아오고 가끔 총을 쏴요 |
| 벌떼 | 작고 빠른 떼. 줄지어 오다가 갑자기 내리꽂혀요 |
| 추적기 | 우주선을 끝까지 쫓아와 들이받아요 |
| 돌격기 | 잠깐 멈춰 빛나다가 우주선을 향해 돌진해요 |
| 혜성 | 경고 표시가 뜬 뒤 대각선으로 빠르게 떨어져요 |
| 분열기 | 부서지면 쫓아오는 조각 3개로 나뉘어요 |
| 저격기 | 빨간 조준선으로 노리다가 아주 빠른 탄을 쏴요 |
| 유령기 | 사라졌다 나타나며 쏴요. 사라져 있을 땐 맞지 않아요 |
| 기뢰 | 가까이 가면 깜빡이다가 사방으로 터져요 |
| 폭격기 | 옆으로 지나가며 떨어뜨린 폭탄이 원형으로 터져요 |
| 수리선 | 주변 적의 체력을 채워 줘요. 먼저 잡는 게 좋아요 |
| 포격기 | 부채꼴, 휘어지는 탄, 원형 탄막을 번갈아 쏴요 |
| 회전포대 | 돌면서 나선 탄막을 뿌려요 |
| 방패선 | 정면 방패가 주포와 미사일을 대부분 막아요. 다른 무기는 통해요 |
| 광선함 | 경고 줄을 보여 준 뒤 아래로 레이저를 쏴요 |
| 장갑선 | 단단하고, 나중엔 유도탄과 점점 빨라지는 탄을 쏴요 |
| 모함 | 추적기를 내보내고 유도탄을 쏴요 |
| 바위 | 소행성대부터 떠다니는 장애물이에요 |

보스는 중간 보스 **순양함**(뒤에 나올수록 유도탄, 폭탄, 레이저 관문이 추가됨)과 최종 보스 **모선**(체력이 줄수록 공격이 바뀜)이에요.

### 출현 패턴

지그재그, 계단, 집게, 원형 편대, 공중제비, 구멍 하나 난 벽, 측면 기습, 호위 편대, 지뢰밭 등 30가지 편대가 섞여 나와요.
지역마다 자주 나오는 편대가 달라요(소행성대는 혜성과 폭격기, 푸른 성운은 벌떼와 유령기, 사건의 지평선은 광선함과 저격기, 은하 중심은 모함과 수리선).

| --- | --- |

| 수수께끼 캡슐 | 절반은 꽝! 나머지는 회복, 자석, 경험치 보너스 중 하나 |
| 코인 | 스킬 트리에서 쓰는 돈. 순양함은 코인 꾸러미를 여러 개 떨어뜨려요 |

### 코인과 스킬 트리

판이 끝나면 그 판에서 주운 코인에 버틴 시간과 클리어 보너스를 더해 코인을 받아요. 뒤쪽 지역일수록 코인을 더 많이 줘요.
처음 화면이나 결과 화면의 **스킬 트리**에서 코인으로 영구 강화를 사요. 한 번 산 강화는 모든 판에 적용돼요.

- 갈래 5개(공격, 방어, 성장, 무기, 전술)에 강화가 45개 있어요. 강화마다 Lv 1~5까지 올릴 수 있어요.
- 위 칸을 정해진 레벨까지 올려야 아래 칸이 열려요. 맨 아래 칸은 비싸지만 강해요.

| 갈래 | 강화 예시 |
| --- | --- |
| 공격 | 화력 강화, 속사, 확산 범위, 치명타, 거함 사냥, 관통탄, 분노, 과부하(투사체 +1) |
| 방어 | 강화 선체, 자가 수리, 장갑판, 회피 기동, 비상 보호막, 반격 장갑, 비상 탈출(한 번 되살아나기) |
| 성장 | 학습, 자력, 탐욕(코인 +), 행운, 다시 뽑기, 보급 탐지, 빠른 출발, 자동 자석, 넓은 선택(카드 4장) |
| 무기 | 무기 7종 숙련, 합체 숙련, 무기 골라 출격 |
| 전술 | 시간 왜곡(적 총알 느리게), 폭탄 강화, 연쇄 폭발, 행운 캡슐, 마무리 사격, 현상금, 과열 가속, 재정비, 보급 확장 |

**초기화**를 누르면 강화를 모두 되돌리고 쓴 코인을 전부 돌려받아요. 그만하기로 끝낸 판은 코인이 남지 않아요.

### 전체 순위

처음 화면의 **조종사** 칸에서 이름(10자까지)을 정해 두면, 판이 끝날 때마다 기록이 그 이름으로 인터넷의 전체 순위표에 저절로 올라가요.
이름 없이 출격하려고 하면 먼저 이름을 정하는 창이 떠요(이름 없이 출격도 할 수 있어요). 이름은 처음 화면에서 언제든 바꿀 수 있어요.
**순위·기록** 화면의 **전체 순위** 탭에서 지역마다 한 사람의 가장 좋은 기록을 순서대로 볼 수 있어요. 결과 화면의 **친구에게 도전장 보내기**로 점수와 주소를 카톡 등으로 보낼 수 있어요.

전체 순위는 무료 Firebase 데이터베이스(`galaxy-defense-5e34a-default-rtdb`)에 연결되어 있어요. `BOARD_DB`를 비우면 기록이 각자의 기기에만 남아요.
다른 데이터베이스로 바꾸는 방법은 아래 [전체 순위 켜기](#전체-순위-켜기-firebase)에 있어요.

### 음악

평소, 중간 보스, 최종 보스 음악이 따로 있어요. 음악과 효과음은 처음 화면이나 일시정지 화면에서 따로 켜고 끌 수 있어요.

### 기록

판이 끝나면 점수, 버틴 시간, 레벨, 격추 수가 남아요. 점수는 격추 점수에 버틴 시간, 레벨, 클리어 보너스를 더한 값이에요.

## 기록 저장

다 끝낸 게임의 점수는 브라우저 저장소(localStorage)에 남아요. 은하수 방어선의 코인, 스킬 트리, 이름도 여기에 저장돼요.
이 기록은 기기와 브라우저마다 따로 저장돼요. 은하수 방어선의 전체 순위만 인터넷에 올라가서 다른 사람과 함께 봐요(이름, 점수, 버틴 시간, 레벨, 격추 수, 기기마다 만든 무작위 번호).

## 인터넷에 올리기 (GitHub Pages)

무료 계정에서는 공개 저장소만 GitHub Pages를 쓸 수 있어요. 저장소가 비공개라면 먼저 **Settings → General** 맨 아래 **Change visibility**에서 공개(Public)로 바꿔요.

1. GitHub 저장소의 **Settings → Pages**로 가요.
2. **Source**를 `Deploy from a branch`로, 브랜치를 `main`, 폴더를 `/ (root)`로 고르고 저장해요.
3. 몇 분 뒤 `https://<사용자 이름>.github.io/<저장소 이름>/` 주소에서 같은 그림 찾기가 열려요.
   주소 끝에 `space/`를 붙이면 은하수 방어선이에요.

## 전체 순위 켜기 (Firebase)

은하수 방어선의 전체 순위는 구글의 무료 서비스인 Firebase Realtime Database에 저장돼요. 저장소 주인이 한 번만 만들면 돼요.

1. [Firebase 콘솔](https://console.firebase.google.com)에 구글 계정으로 들어가 **프로젝트 만들기**를 눌러요. 이름은 자유롭게 정하고, Google 애널리틱스는 꺼도 돼요.
2. 왼쪽 메뉴(빌드 또는 모든 제품)에서 **Realtime Database**를 열고 **데이터베이스 만들기**를 눌러요. 위치는 **싱가포르(asia-southeast1)**, 보안 규칙은 **잠금 모드**로 시작해요.
3. **규칙** 탭의 내용을 모두 지우고 아래 규칙을 붙여 넣은 뒤 **게시**를 눌러요. 누구나 순위를 읽고 새 기록을 올릴 수 있지만, 이미 올라간 기록은 바꾸거나 지울 수 없어요.
4. **데이터** 탭 위쪽 주소의 맨 앞부분이 데이터베이스 이름이에요(예: `https://galaxy-defense-5e34a-default-rtdb.…`이면 `galaxy-defense-5e34a-default-rtdb`).
   이 이름을 `space/index.html`의 `const BOARD_DB = '…';` 따옴표 안에 넣어요. 지역(싱가포르, 미국, 벨기에)에 맞는 주소는 게임이 알아서 찾아요.

```json
{
  "rules": {
    "v1": {
      "scores": {
        "$stage": {
          ".read": "$stage.matches(/^s[1-5]$/)",
          ".indexOn": [
            "score"
          ],
          "$id": {
            ".write": "!data.exists() && $stage.matches(/^s[1-5]$/)",
            ".validate": "newData.hasChildren(['name', 'score', 'time', 'level', 'kills', 'clear', 'pid', 'at'])",
            "name": {
              ".validate": "newData.isString() && newData.val().length >= 1 && newData.val().length <= 12"
            },
            "score": {
```
