# 웹 게임 모음

폰과 컴퓨터 브라우저에서 모두 되는 웹 게임들이에요. 로그인 없이 누구나 할 수 있고, 점수는 각자의 브라우저에 기록돼요.

| 게임 | 파일 | 소개 |
| --- | --- | --- |
| 같은 그림 찾기 | `index.html` | 카드를 두 장씩 뒤집어 같은 그림을 찾는 기억력 게임 |
| 전투의 미 | `space/index.html` | 13분을 버티며 경험치로 스킬을 키우고, 마지막 모선을 격추하는 우주 슈팅 게임. 스킬 트리와 친구들과 겨루는 전체 순위가 있어요 |

게임마다 파일 하나에 모두 들어 있어요. 설치할 것 없이 브라우저로 열면 바로 시작돼요.

## 같은 그림 찾기

- 난이도: 쉬움(6쌍), 보통(8쌍), 어려움(12쌍)
- 카드를 두 장 뒤집어 같은 그림이면 짝을 찾은 거예요.
- 첫 카드를 뒤집는 순간부터 시간이 흘러요.

| 점수 | |
| --- | --- |
| 짝 맞추기 | +100 |
| 연속 보너스 | 2연속 +50, 3연속 +100, 4연속 +150 … |
| 틀린 시도 | −10 |
| 시간 보너스 | 기준 시간(쉬움 60초 · 보통 90초 · 어려움 150초)에서 남은 1초당 +10 |

난이도마다 최고 점수, 가장 빠른 판, 상위 10개 기록을 볼 수 있어요.

## 전투의 미

### 진행

- 지역 5곳(달 궤도 → 소행성대 → 푸른 성운 → 사건의 지평선 → 은하 중심). 앞 지역을 클리어해야 다음 지역이 열려요.
- 13분을 버티면 최종 보스 **모선**이 나타나요. 모선을 격추하면 클리어예요.
- 3:00, 6:30, 10:00에는 중간 보스 **순양함**이 나와요. 순양함은 보급 상자를 꼭 떨어뜨려요.
- 시간이 지날수록 적이 많아지고 단단해지고 총알이 빨라져요. 뒤쪽 지역일수록 더 세요.
- 체력은 바로 보여요. 다 닳으면 작전 실패예요.
- 지역 목록 맨 아래의 **∞ 무한 모드**는 처음부터 열려 있어요. 아래 [무한 모드](#무한-모드)를 보세요.

### 조작

- 화면 아무 곳이나 누른 채로 끌면 우주선이 따라와요. 공격은 저절로 해요.
- 키보드: 방향키나 WASD로 움직이기, Shift는 천천히, 숫자키로 스킬 고르기, P로 일시정지
- 우주선 가운데 빛나는 점에 맞을 때만 다쳐요.
- 적 총알은 어두운 테두리가 있는 밝은 구슬이라 내 공격이 화려해도 잘 보여요. 그래도 헷갈리면 처음 화면이나 일시정지 화면에서 **내 효과 흐리게**를 고르세요. 내 공격과 폭발이 옅어져요.

### 경험치와 스킬

적을 격추하면 경험치 결정이 떨어져요. 가까이 가거나 결정이 우주선 높이까지 내려오면 저절로 빨려 들어와요.
레벨이 오르면 스킬 3개 중 하나를 골라요. 무기는 5칸, 장비는 5칸이고(무한 모드는 6칸씩) 각각 Lv 5까지 올라가요.
출격할 때는 [전투기](#격납고와-전투기)의 고유 공격만 들고 시작하고, 무기는 레벨 업으로 하나씩 얻어요.

| 무기 | 하는 일 |
| --- | --- |
| 주포 | 위로 곧게 쏘는 기본 포 |
| 유도 미사일 | 가까운 적을 쫓아가는 미사일 |
| 궤도 드론 | 우주선 둘레를 돌며 부딪치는 적을 때림 |
| 레이저 | 앞을 꿰뚫는 광선을 주기적으로 쏨 |
| 충격파 | 주변 적을 밀어내고 적 총알을 지움 |
| 번개 | 무작위 적에게 떨어져 옆 적으로 번짐 |
| 역장 | 우주선 둘레의 역장이 닿는 적에게 계속 피해를 주고 살짝 밀어냄 |
| 회전 톱날 | 부채꼴로 날아갔다 돌아오며 닿는 적을 모두 벰 |
| 화염 방사기 | 앞쪽 부채꼴 안의 적을 계속 태움 |

| 장비 | 효과(레벨마다) |
| --- | --- |
| 강화 장갑 | 최대 체력 +20 |
| 나노 수리 | 초당 체력 0.4 회복 |
| 냉각 장치 | 재사용 시간 −7% |
| 증폭기 | 모든 피해 +10% |
| 확산기 | 범위와 크기 +10% |
| 견인 빔 | 경험치를 끌어오는 거리 +35% |
| 행운 부적 | 아이템이 나올 확률 +20% |
| 흡수 장치 | 적을 격추할 때마다 체력 0.08 회복 |
| 자이로 안정기 | 투사체 속도 +12% |
| 연료 탱크 | 사거리와 지속 시간 +10% |

### 스킬 합체

무기를 Lv 5까지 올리고 짝이 되는 장비를 가진 채 **보급 상자**를 열면 합체 카드가 나와요.
합체할 수 있는 스킬이 여러 개면 그중 하나가 무작위로 나오고, 원하지 않으면 **건너뛰기**를 눌러 평소처럼 스킬 하나를 고르면 돼요(그 합체는 다음 상자에 다시 나올 수 있어요).
무기 칸이 5개라 한 판에 합체 스킬을 최대 5개까지 가질 수 있어요(같은 합체 스킬은 하나씩만).

| 재료 | 합체 스킬 |
| --- | --- |
| 주포 Lv 5 + 증폭기 | 플라즈마 포: 꿰뚫는 플라즈마를 7발씩 쏴요 |
| 유도 미사일 Lv 5 + 냉각 장치 | 벌떼 미사일: 유도 미사일 6발을 쉴 새 없이 쏴요 |
| 궤도 드론 Lv 5 + 강화 장갑 | 수호 위성: 큰 위성 6개가 돌며 총알까지 막아요 |
| 레이저 Lv 5 + 확산기 | 은하 절단기: 굵은 광선이 좌우로 훑어요 |
| 충격파 Lv 5 + 나노 수리 | 생명 파동: 맞힌 적만큼 체력을 회복해요 |
| 번개 Lv 5 + 견인 빔 | 폭풍 핵: 번개가 쉬지 않고 쏟아져요 |
| 역장 Lv 5 + 흡수 장치 | 흡수 역장: 커다란 역장이 적을 녹이며 체력을 흡수하고, 안에 들어온 적 총알을 느리게 해요 |
| 회전 톱날 Lv 5 + 자이로 안정기 | 은하 원반: 커다란 원반 6개가 나선을 그리며 휩쓸어요 |
| 화염 방사기 Lv 5 + 연료 탱크 | 태양 플레어: 거대한 불꽃을 뿜고, 2초마다 사방으로 불꽃이 터져요 |

레벨 업 화면과 일시정지 화면에서 합체 레시피와 지금 진행 상황(예: 주포 Lv 3/5 + 증폭기 ✓)을 볼 수 있어요.
레벨 업 카드와 관련된 레시피는 강조돼요. 레벨 업 화면에는 이번 판과 관련된 레시피만 나오고, **레시피 모두 보기**로 나머지도 볼 수 있어요.

### 궁극 합체

합체 스킬 2개를 가진 채 보급 상자를 열면 두 합체 스킬을 하나의 **궁극기**로 합칠 수 있어요. 일반 지역에서는 한 판에 한 번, 무한 모드에서는 몇 번이든 할 수 있어요.
합체할 때 화면이 무지개 빛으로 번쩍이고, 궁극기는 슬롯에서 금색으로 빛나요. 어떤 궁극기가 될지는 두 스킬의 계열로 정해져요.

- 불 계열: 주포, 유도 미사일, 화염 방사기
- 에너지 계열: 레이저, 번개, 회전 톱날
- 수호 계열: 궤도 드론, 충격파, 역장

| 계열 조합 | 궁극기 |
| --- | --- |
| 불 + 불 | 유성 폭풍: 불타는 유성이 쉬지 않고 적에게 쏟아져요 |
| 에너지 + 에너지 | 뇌신: 갈라지는 번개와 번개 기둥이 화면을 휩쓸어요 |
| 수호 + 수호 | 수호 성좌: 별 7개가 이은 별자리가 돌며 적을 베고 총알을 막아요 |
| 에너지 + 불 | 초신성 포: 힘을 모아 쏜 초신성 포탄이 적을 꿰뚫고 크게 터져요 |
| 불 + 수호 | 불사조: 불꽃 새가 날아들며 적을 태우고 체력을 채워 줘요 |
| 에너지 + 수호 | 블랙홀: 적이 몰린 곳에 블랙홀을 열어 빨아들이고 터뜨려요 |

일시정지 화면의 **궁극 합체** 칸에서 이 표를 볼 수 있어요.

### 격납고와 전투기

처음 화면의 **격납고**에서 코인으로 전투기를 사고, 탈 전투기를 골라요. 전투기마다 체력, 맞는 점 크기, 고유 공격이 달라요.
고유 공격은 판 내내 저절로 쏘고, 레벨 10·25·40에서 한 단계씩 강해져요(줄이 늘거나 두 발씩 쏘는 식).

| 전투기 | 값 | 고유 공격 | 특징 |
| --- | --- | --- | --- |
| 스타라이트 | 기본 | 쌍발 광탄: 곧게 쏘는 광탄 | 무난한 기본 전투기 |
| 와스프 | 4,000 | 부채 산탄: 다섯 갈래로 퍼지는 산탄 | 맞는 점이 작아 피하기 쉬움, 체력 낮음 |
| 타이탄 | 6,000 | 중포탄: 적을 꿰뚫고 마지막에 터지는 큰 포탄 | 체력 높고 받는 피해 −10%, 맞는 점이 큼 |
| 세라프 | 8,000 | 유도 광구: 끝까지 쫓아가는 빛 구슬 | 초당 체력 0.5 회복, 끌어오는 거리 +30% |
| 녹스 | 10,000 | 레일건: 가장 단단한 적을 노려 한 줄로 꿰뚫음 | 치명타 확률 +15% |
| 노바 드래곤 | 18,000 | 용의 숨결: 둘레를 도는 불꽃 구슬과 화염탄 | 모든 피해 +15%, 경험치 +10% |

산 전투기는 계정에도 저장돼서 다른 기기에서도 그대로 써요. 전체 순위에는 어떤 전투기로 했는지도 나와요.

### 무한 모드

끝없이 버티며 점수를 쌓는 모드예요. 처음부터 어렵고(지역 1분째 수준에서 시작), 버틸수록 끝없이 세져요. 스킬 트리를 키울수록 오래 버티고 점수도 크게 올라가요.

- 3분마다 **구역**이 바뀌어요. 하늘과 나오는 적이 다른 지역 것으로 바뀌고, 적이 더 단단해지고, 격추 점수 배율이 0.25씩 올라가요.
- 2분에 첫 보스가 나오고, 그 뒤로 2분 30초마다 보스가 나와요. 네 번째 보스마다 **모선**이 나오고, 모선을 잡으면 보급 상자 2개를 주고 판은 계속돼요.
- **콤보**: 적을 2.5초 안에 계속 격추하면 콤보가 쌓이고, 콤보 150마다 점수 배율이 +1(최대 ×3)이에요. 한 번이라도 맞으면 콤보가 끊겨요.
- 궁극 합체 횟수 제한이 없어요. 무기와 장비 칸도 6칸씩이에요.
- 일시정지 화면의 **여기서 끝내고 점수 받기**를 누르면 지금까지 점수와 코인을 받고 끝낼 수 있어요.
- 무한 모드 기록은 전체 순위의 **∞ 무한** 탭에 따로 모여요.

### 적

| 적 | 특징 |
| --- | --- |
| 정찰기 | 기본 적. 여러 편대로 날아오고 가끔 총을 쏴요 |
| 벌떼 | 작고 빠른 떼. 줄지어 오다가 갑자기 내리꽂혀요 |
| 추적기 | 우주선을 끝까지 쫓아와 들이받아요 |
| 돌격기 | 잠깐 멈춰 빛나다가 우주선을 향해 돌진해요 |
| 혜성 | 경고 표시가 뜬 뒤 대각선으로 빠르게 떨어져요 |
| 분열기 | 부서지면 쫓아오는 조각 3개로 나뉘어요 |
| 저격기 | 빨간 조준선으로 노리다가 아주 빠른 탄을 쏴요 |
| 유령기 | 사라졌다 나타나며 쏴요. 사라져 있을 땐 맞지 않아요 |
| 기뢰 | 가까이 가면 깜빡이다가 사방으로 터져요 |
| 폭격기 | 옆으로 지나가며 떨어뜨린 폭탄이 원형으로 터져요 |
| 수리선 | 주변 적의 체력을 채워 줘요. 먼저 잡는 게 좋아요 |
| 포격기 | 부채꼴, 휘어지는 탄, 원형 탄막을 번갈아 쏴요 |
| 회전포대 | 돌면서 나선 탄막을 뿌려요 |
| 방패선 | 정면 방패가 주포와 미사일을 대부분 막아요. 다른 무기는 통해요 |
| 광선함 | 경고 줄을 보여 준 뒤 아래로 레이저를 쏴요 |
| 장갑선 | 단단하고, 나중엔 유도탄과 점점 빨라지는 탄을 쏴요 |
| 모함 | 추적기를 내보내고 유도탄을 쏴요 |
| 바위 | 소행성대부터 떠다니는 장애물이에요 |

보스는 중간 보스 **순양함**(뒤에 나올수록 유도탄, 폭탄, 레이저 관문이 추가됨)과 최종 보스 **모선**(체력이 줄수록 공격이 바뀜)이에요.

### 출현 패턴

지그재그, 계단, 집게, 원형 편대, 공중제비, 구멍 하나 난 벽, 측면 기습, 호위 편대, 지뢰밭 등 30가지 편대가 섞여 나와요.
지역마다 자주 나오는 편대가 달라요(소행성대는 혜성과 폭격기, 푸른 성운은 벌떼와 유령기, 사건의 지평선은 광선함과 저격기, 은하 중심은 모함과 수리선).

### 코인과 스킬 트리

판이 끝나면 그 판에서 주운 코인에 버틴 시간과 클리어 보너스를 더해 코인을 받아요. 뒤쪽 지역일수록 코인을 더 많이 줘요.
처음 화면이나 결과 화면의 **스킬 트리**에서 코인으로 영구 강화를 사요. 한 번 산 강화는 모든 판에 적용돼요.

- 갈래 6개(공격, 방어, 성장, 무기, 전술, 궁극)에 강화가 68개 있어요. 강화마다 최대 레벨이 달라요(1~10).
- 레벨을 올릴수록 값이 점점 비싸져요. 처음엔 싸지만 높은 레벨은 수천 코인이에요. 전부 다 올리려면 12만 코인이 넘게 들어요.
- 위 칸을 정해진 레벨까지 올려야 아래 칸이 열려요. 맨 아래 칸은 비싸지만 강해요.
- **무기 숙련**을 올리면 그 무기 모양이 바뀌어요. Lv 2에서 색이 바뀌고, Lv 4에서 모양이 바뀌고(주포는 다이아몬드 탄, 레이저는 나선, 번개는 갈래, 드론은 잔상 등), Lv 5에서 잔상과 반짝임이 붙은 최종 모습이 돼요.

| 갈래 | 강화 예시 |
| --- | --- |
| 공격 | 화력 강화, 속사, 확산 범위, 치명타, 거함 사냥, 치명 강화, 관통탄, 분노, 탄속 가속, 집중 포화, 정예 사냥, 과부하(투사체 +1) |
| 방어 | 강화 선체, 자가 수리, 장갑판, 의무 키트, 회피 기동, 생명력, 비상 보호막, 반격 장갑, 회피 확률, 튼튼한 몸체, 위기 회복, 비상 탈출(한 번 되살아나기) |
| 성장 | 학습, 자력, 탐욕(코인 +), 행운, 다시 뽑기, 보급 탐지, 빠른 출발, 자동 자석, 보스 경험치, 이자, 행운의 카드, 넓은 선택(카드 4장) |
| 무기 | 무기 9종 숙련(모양도 바뀜), 합체 숙련, 무기 골라 출격, 빠른 합체 |
| 전술 | 시간 왜곡(적 총알 느리게), 폭탄 강화, 연쇄 폭발, 행운 캡슐, 마무리 사격, 현상금, 과열 가속, 재정비, 보급 확장, 위기 폭탄, 점수 배율, 전리품 회수 |
| 궁극 | 궁극 출력, 궁극 가속, 궁극 범위, 궁극 준비, 궁극 보호막, 무한 출발, 무한 점수, 무지개 궁극(궁극기가 무지갯빛으로 바뀜) |

**초기화**를 누르면 강화를 모두 되돌리고 쓴 코인을 전부 돌려받아요. 그만하기로 끝낸 판은 코인이 남지 않아요.

### 전체 순위

처음 화면의 **조종사** 칸에서 이름(10자까지)을 정해 두면, 판이 끝날 때마다 기록이 그 이름으로 인터넷의 전체 순위표에 저절로 올라가요.
이름 없이 출격하려고 하면 먼저 이름을 정하는 창이 떠요(이름 없이 출격도 할 수 있어요). 이름은 처음 화면에서 언제든 바꿀 수 있어요.

### 어디서나 이어하기 (계정)

이름을 정할 때 **비밀번호**(4자 이상)도 넣으면 계정이 만들어져요. 열린 지역, 클리어, 코인, 스킬 트리, 기록이 서버에 저절로 저장돼요.
다른 폰이나 다른 앱(카카오톡, 크롬 등)에서 처음 화면의 **이어하기**를 누르고 같은 이름과 비밀번호를 넣으면 그대로 이어서 할 수 있어요.

- 처음 연결할 때는 그 기기에 있던 기록과 계정의 기록 중 더 좋은 쪽을 합쳐요.
- 그다음부터는 가장 최근에 한 곳의 진행 상황을 따라가요. 게임 화면으로 돌아올 때마다 새 내용을 받아 와요.
- 같은 이름은 한 계정만 쓸 수 있어요. 비밀번호가 틀리면 "이미 다른 사람이 쓰는 이름이에요"라고 나와요.
- 비밀번호는 기기에서 긴 열쇠로 바꾼 뒤 그 열쇠로만 서버에 접근해서, 비밀번호 자체는 서버에 올라가지 않아요. 그래도 다른 곳에 쓰는 비밀번호와는 다르게 정해 주세요.
- 비밀번호를 비우면 이름은 그 기기에만 저장돼요.

**구글로 로그인**도 할 수 있어요(아래 [구글 로그인 켜기](#구글-로그인-켜기)를 마친 뒤).

- 처음 구글로 로그인하면 게임에서 쓸 이름을 정해요. 이름과 비밀번호로 만든 계정이 이미 있으면 그 비밀번호도 넣어서 같은 계정에 구글을 붙여요.
- 이름과 비밀번호 계정에 연결된 상태에서 **Google 로그인도 연결하기**를 누르면, 그다음부터 다른 곳에서는 구글 로그인만으로 들어올 수 있어요.
- 카카오톡 같은 앱 안의 브라우저에서는 구글이 로그인을 막아요. 이때는 **Safari·크롬에서 열기**를 누르거나, 이름과 비밀번호로 들어오면 돼요.
**순위·기록** 화면의 **전체 순위** 탭에서 지역마다(그리고 무한 모드 따로) 한 사람의 가장 좋은 기록을 순서대로 볼 수 있어요. 결과 화면의 **친구에게 도전장 보내기**로 점수와 주소를 카톡 등으로 보낼 수 있어요.

전체 순위는 무료 Firebase 데이터베이스(`galaxy-defense-5e34a-default-rtdb`)에 연결되어 있어요. `BOARD_DB`를 비우면 기록이 각자의 기기에만 남아요.
다른 데이터베이스로 바꾸는 방법은 아래 [전체 순위 켜기](#전체-순위-켜기-firebase)에 있어요.

### 음악

평소, 중간 보스, 최종 보스 음악이 따로 있어요. 음악과 효과음은 처음 화면이나 일시정지 화면에서 따로 켜고 끌 수 있어요.

### 기록

판이 끝나면 점수, 버틴 시간, 레벨, 격추 수가 남아요. 점수는 격추 점수에 버틴 시간, 레벨, 클리어 보너스를 더한 값이에요.
무한 모드 점수는 격추 점수(구역 배율과 콤보 배율이 붙음)에 버틴 시간과 레벨을 더하고, 스킬 트리의 점수 배율과 무한 점수를 곱한 값이에요.

## 기록 저장

다 끝낸 게임의 점수는 브라우저 저장소(localStorage)에 남아요. '전투의 미'의 코인, 스킬 트리, 이름도 여기에 저장돼요.
이 기록은 기기와 브라우저마다 따로 저장돼요. 계정을 연결하면 서버에도 저장되어 어디서나 이어서 할 수 있어요. '전투의 미'의 전체 순위만 인터넷에 올라가서 다른 사람과 함께 봐요(이름, 점수, 버틴 시간, 레벨, 격추 수, 전투기, 기기마다 만든 무작위 번호).

## 인터넷에 올리기 (GitHub Pages)

무료 계정에서는 공개 저장소만 GitHub Pages를 쓸 수 있어요. 저장소가 비공개라면 먼저 **Settings → General** 맨 아래 **Change visibility**에서 공개(Public)로 바꿔요.

1. GitHub 저장소의 **Settings → Pages**로 가요.
2. **Source**를 `Deploy from a branch`로, 브랜치를 `main`, 폴더를 `/ (root)`로 고르고 저장해요.
3. 몇 분 뒤 `https://<사용자 이름>.github.io/<저장소 이름>/` 주소에서 같은 그림 찾기가 열려요.
   주소 끝에 `space/`를 붙이면 '전투의 미'예요.

## 전체 순위 켜기 (Firebase)

'전투의 미'의 전체 순위는 구글의 무료 서비스인 Firebase Realtime Database에 저장돼요. 저장소 주인이 한 번만 만들면 돼요.

1. [Firebase 콘솔](https://console.firebase.google.com)에 구글 계정으로 들어가 **프로젝트 만들기**를 눌러요. 이름은 자유롭게 정하고, Google 애널리틱스는 꺼도 돼요.
2. 왼쪽 메뉴(빌드 또는 모든 제품)에서 **Realtime Database**를 열고 **데이터베이스 만들기**를 눌러요. 위치는 **싱가포르(asia-southeast1)**, 보안 규칙은 **잠금 모드**로 시작해요.
3. **규칙** 탭의 내용을 모두 지우고 아래 규칙을 붙여 넣은 뒤 **게시**를 눌러요. 누구나 순위를 읽고 새 기록을 올릴 수 있지만, 이미 올라간 기록은 바꾸거나 지울 수 없어요. 계정 자료는 열쇠를 아는 사람만 읽고 쓸 수 있고, 계정이나 이름 목록을 통째로 볼 수는 없어요.
4. **데이터** 탭 위쪽 주소의 맨 앞부분이 데이터베이스 이름이에요(예: `https://galaxy-defense-5e34a-default-rtdb.…`이면 `galaxy-defense-5e34a-default-rtdb`).
   이 이름을 `space/index.html`의 `const BOARD_DB = '…';` 따옴표 안에 넣어요. 지역(싱가포르, 미국, 벨기에)에 맞는 주소는 게임이 알아서 찾아요.

```json
{
  "rules": {
    "v1": {
      "scores": {
        "$stage": {
          ".read": "$stage.matches(/^s[1-6]$/)",
          ".indexOn": [
            "score"
          ],
          "$id": {
            ".write": "!data.exists() && $stage.matches(/^s[1-6]$/)",
            ".validate": "newData.hasChildren(['name', 'score', 'time', 'level', 'kills', 'clear', 'pid', 'at'])",
            "name": {
              ".validate": "newData.isString() && newData.val().length >= 1 && newData.val().length <= 12"
            },
            "score": {
              ".validate": "newData.isNumber() && newData.val() >= 0 && newData.val() <= 999999999"
            },
            "time": {
              ".validate": "newData.isNumber() && newData.val() >= 0 && newData.val() <= 86400"
            },
            "level": {
              ".validate": "newData.isNumber() && newData.val() >= 0 && newData.val() <= 9999"
            },
            "kills": {
              ".validate": "newData.isNumber() && newData.val() >= 0 && newData.val() <= 99999999"
            },
            "clear": {
              ".validate": "newData.isBoolean()"
            },
            "pid": {
              ".validate": "newData.isString() && newData.val().length <= 24"
            },
            "at": {
              ".validate": "newData.val() === now"
            },
            "ship": {
              ".validate": "newData.isString() && newData.val().length <= 12"
            },
            "$other": {
              ".validate": false
            }
          }
        }
      },
      "accounts": {
        "$key": {
          ".read": "$key.matches(/^[0-9a-f]{64}$/)",
          ".write": "$key.matches(/^[0-9a-f]{64}$/)",
          ".validate": "newData.hasChildren(['rev', 'data', 'at'])",
          "rev": {
            ".validate": "newData.isNumber() && newData.val() >= 0"
          },
          "data": {
            ".validate": "newData.isString() && newData.val().length <= 100000"
          },
          "at": {
            ".validate": "newData.val() === now"
          },
          "$other": {
            ".validate": false
          }
        }
      },
      "names": {
        "$name": {
          ".read": "$name.matches(/^[0-9a-f]{64}$/)",
          ".write": "!data.exists() && $name.matches(/^[0-9a-f]{64}$/)",
          ".validate": "newData.isString() && newData.val().matches(/^[0-9a-f]{64}$/)"
        }
      },
      "users": {
        "$uid": {
          ".read": "auth != null && auth.uid === $uid",
          ".write": "auth != null && auth.uid === $uid",
          ".validate": "newData.hasChildren(['key', 'owner', 'name'])",
          "key": {
            ".validate": "newData.isString() && newData.val().matches(/^[0-9a-f]{64}$/)"
          },
          "owner": {
            ".validate": "newData.isString() && newData.val().matches(/^[0-9a-f]{64}$/)"
          },
          "name": {
            ".validate": "newData.isString() && newData.val().length >= 1 && newData.val().length <= 12"
          },
          "$other": {
            ".validate": false
          }
        }
      }
    }
  }
}
```

이상한 기록이 올라오면 Firebase 콘솔의 **데이터** 탭에서 직접 지울 수 있어요.

예전 규칙(무한 모드 `s6`와 전투기 `ship` 칸이 없는 규칙)이 게시되어 있어도 게임은 돌아가요. 지역 기록은 전투기 이름만 빼고 올라가고, 무한 모드 순위는 "준비 중"으로 나와요. 위 규칙을 게시하면 둘 다 켜져요.

## 구글 로그인 켜기

1. Firebase 콘솔 왼쪽 메뉴 **보안 → Authentication**에서 **시작하기**를 눌러요.
2. **로그인 방법** 탭에서 **Google**을 고르고 **사용 설정**을 켠 뒤, 프로젝트 지원 이메일을 골라 **저장**해요.
3. **설정** 탭의 **승인된 도메인**에서 **도메인 추가**를 눌러 `kswksj7867-a11y.github.io`를 넣어요.
4. **프로젝트 설정**(톱니바퀴) → **내 앱**에서 웹 아이콘(`</>`)을 눌러 앱을 등록하고, 나오는 `firebaseConfig` 값을 `space/index.html`의 `FIREBASE_CONFIG`에 넣어요(지금은 `galaxy-defense-5e34a` 프로젝트 값이 들어 있어요).
   이 값(apiKey 포함)은 원래 공개되는 값이에요. 데이터는 보안 규칙과 승인된 도메인이 지켜요.

구글 계정과 게임 계정의 연결은 `v1/users/<구글 사용자 번호>`에 저장되고, 위 규칙에 따라 본인만 읽고 쓸 수 있어요.
