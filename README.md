# 웹 게임 모음

폰과 컴퓨터 브라우저에서 모두 되는 웹 게임들이에요. 로그인 없이 누구나 할 수 있고, 점수는 각자의 브라우저에 기록돼요.

| 게임 | 파일 | 소개 |
| --- | --- | --- |
| 같은 그림 찾기 | `index.html` | 카드를 두 장씩 뒤집어 같은 그림을 찾는 기억력 게임 |
| 은하수 방어선 | `space/index.html` | 13분을 버티며 경험치로 스킬을 키우고, 마지막 모선을 격추하는 우주 슈팅 게임 |

게임마다 파일 하나에 모두 들어 있어요. 설치할 것 없이 브라우저로 열면 바로 시작돼요.

## 같은 그림 찾기

- 난이도: 쉬움(6쌍), 보통(8쌍), 어려움(12쌍)
- 카드를 두 장 뒤집어 같은 그림이면 짝을 찾은 거예요.
- 첫 카드를 뒤집는 순간부터 시간이 흘러요.

| 점수 | |
| --- | --- |
| 짝 맞추기 | +100 |
| 연속 보너스 | 2연속 +50, 3연속 +100, 4연속 +150 … |
| 틀린 시도 | −10 |
| 시간 보너스 | 기준 시간(쉬움 60초 · 보통 90초 · 어려움 150초)에서 남은 1초당 +10 |

난이도마다 최고 점수, 가장 빠른 판, 상위 10개 기록을 볼 수 있어요.

## 은하수 방어선

### 진행

- 지역 5곳(달 궤도 → 소행성대 → 푸른 성운 → 사건의 지평선 → 은하 중심). 앞 지역을 클리어해야 다음 지역이 열려요.
- 13분을 버티면 최종 보스 **모선**이 나타나요. 모선을 격추하면 클리어예요.
- 3:00, 6:30, 10:00에는 중간 보스 **순양함**이 나와요. 순양함은 보급 상자를 꼭 떨어뜨려요.
- 시간이 지날수록 적이 많아지고 단단해지고 총알이 빨라져요. 뒤쪽 지역일수록 더 세요.
- 체력은 바로 보여요. 다 닳으면 작전 실패예요.

### 조작

- 화면 아무 곳이나 누른 채로 끌면 우주선이 따라와요. 공격은 저절로 해요.
- 키보드: 방향키나 WASD로 움직이기, Shift는 천천히, 1·2·3으로 스킬 고르기, P로 일시정지
- 우주선 가운데 빛나는 점에 맞을 때만 다쳐요.

### 경험치와 스킬

적을 격추하면 경험치 결정이 떨어져요. 가까이 가거나 결정이 우주선 높이까지 내려오면 저절로 빨려 들어와요.
레벨이 오르면 스킬 3개 중 하나를 골라요. 무기는 4칸, 장비는 4칸이고 각각 Lv 5까지 올라가요.

| 무기 | 하는 일 |
| --- | --- |
| 주포 | 위로 곧게 쏘는 기본 포 |
| 유도 미사일 | 가까운 적을 쫓아가는 미사일 |
| 궤도 드론 | 우주선 둘레를 돌며 부딪치는 적을 때림 |
| 레이저 | 앞을 꿰뚫는 광선을 주기적으로 쏨 |
| 충격파 | 주변 적을 밀어내고 적 총알을 지움 |
| 번개 | 무작위 적에게 떨어져 옆 적으로 번짐 |

| 장비 | 효과(레벨마다) |
| --- | --- |
| 강화 장갑 | 최대 체력 +20 |
| 나노 수리 | 초당 체력 0.4 회복 |
| 냉각 장치 | 재사용 시간 −7% |
| 증폭기 | 모든 피해 +10% |
| 확산기 | 범위와 크기 +10% |
| 견인 빔 | 경험치를 끌어오는 거리 +35% |
| 행운 부적 | 아이템이 나올 확률 +20% |

### 스킬 합체

무기를 Lv 5까지 올리고 짝이 되는 장비를 가진 채 **보급 상자**를 열면 더 강한 스킬로 합체돼요.

| 재료 | 합체 스킬 |
| --- | --- |
| 주포 Lv 5 + 증폭기 | 플라즈마 포: 꿰뚫는 플라즈마를 7발씩 쏴요 |
| 유도 미사일 Lv 5 + 냉각 장치 | 벌떼 미사일: 유도 미사일 6발을 쉴 새 없이 쏴요 |
| 궤도 드론 Lv 5 + 강화 장갑 | 수호 위성: 큰 위성 6개가 돌며 총알까지 막아요 |
| 레이저 Lv 5 + 확산기 | 은하 절단기: 굵은 광선이 좌우로 훑어요 |
| 충격파 Lv 5 + 나노 수리 | 생명 파동: 맞힌 적만큼 체력을 회복해요 |
| 번개 Lv 5 + 견인 빔 | 폭풍 핵: 번개가 쉬지 않고 쏟아져요 |

레벨 업 화면과 일시정지 화면에서 합체 레시피와 지금 진행 상황(예: 주포 Lv 3/5 + 증폭기 ✓)을 볼 수 있어요.
레벨 업 카드와 관련된 레시피는 강조돼요.

### 적

| 적 | 특징 |
| --- | --- |
| 정찰기 | 기본 적. 여러 편대로 날아오고 가끔 총을 쏴요 |
| 벌떼 | 작고 빠른 떼. 줄지어 오다가 갑자기 내리꽂혀요 |
| 추적기 | 우주선을 끝까지 쫓아와 들이받아요 |
| 돌격기 | 잠깐 멈춰 빛나다가 우주선을 향해 돌진해요 |
| 혜성 | 경고 표시가 뜬 뒤 대각선으로 빠르게 떨어져요 |
| 분열기 | 부서지면 쫓아오는 조각 3개로 나뉘어요 |
| 저격기 | 빨간 조준선으로 노리다가 아주 빠른 탄을 쏴요 |
| 유령기 | 사라졌다 나타나며 쏴요. 사라져 있을 땐 맞지 않아요 |
| 기뢰 | 가까이 가면 깜빡이다가 사방으로 터져요 |
| 폭격기 | 옆으로 지나가며 떨어뜨린 폭탄이 원형으로 터져요 |
| 수리선 | 주변 적의 체력을 채워 줘요. 먼저 잡는 게 좋아요 |
| 포격기 | 부채꼴, 휘어지는 탄, 원형 탄막을 번갈아 쏴요 |
| 회전포대 | 돌면서 나선 탄막을 뿌려요 |
| 방패선 | 정면 방패가 주포와 미사일을 대부분 막아요. 다른 무기는 통해요 |
| 광선함 | 경고 줄을 보여 준 뒤 아래로 레이저를 쏴요 |
| 장갑선 | 단단하고, 나중엔 유도탄과 점점 빨라지는 탄을 쏴요 |
| 모함 | 추적기를 내보내고 유도탄을 쏴요 |
| 바위 | 소행성대부터 떠다니는 장애물이에요 |

보스는 중간 보스 **순양함**(뒤에 나올수록 유도탄, 폭탄, 레이저 관문이 추가됨)과 최종 보스 **모선**(체력이 줄수록 공격이 바뀜)이에요.

### 출현 패턴

지그재그, 계단, 집게, 원형 편대, 공중제비, 구멍 하나 난 벽, 측면 기습, 호위 편대, 지뢰밭 등 30가지 편대가 섞여 나와요.
지역마다 자주 나오는 편대가 달라요(소행성대는 혜성과 폭격기, 푸른 성운은 벌떼와 유령기, 사건의 지평선은 광선함과 저격기, 은하 중심은 모함과 수리선).

### 떨어지는 아이템

| 아이템 | 효과 |
| --- | --- |
| 자석 | 화면에 있는 경험치를 모두 끌어와요 |
| 회복 | 체력 +30 |
| 폭탄 | 적 총알을 모두 지우고 화면의 적에게 큰 피해 |
| 보급 상자 (드묾) | 합체할 수 있으면 합체, 아니면 스킬 하나를 골라요 |
| 수수께끼 캡슐 | 절반은 꽝! 나머지는 회복, 자석, 경험치 보너스 중 하나 |

### 음악

평소, 중간 보스, 최종 보스 음악이 따로 있어요. 음악과 효과음은 처음 화면이나 일시정지 화면에서 따로 켜고 끌 수 있어요.

### 기록

판이 끝나면 점수, 버틴 시간, 레벨, 격추 수가 남아요. 점수는 격추 점수에 버틴 시간, 레벨, 클리어 보너스를 더한 값이에요.

## 기록 저장

다 끝낸 게임의 점수는 브라우저 저장소(localStorage)에 남아요.
기록은 기기와 브라우저마다 따로 저장되고 다른 사람과 공유되지 않아요.

## 인터넷에 올리기 (GitHub Pages)

무료 계정에서는 공개 저장소만 GitHub Pages를 쓸 수 있어요. 저장소가 비공개라면 먼저 **Settings → General** 맨 아래 **Change visibility**에서 공개(Public)로 바꿔요.

1. GitHub 저장소의 **Settings → Pages**로 가요.
2. **Source**를 `Deploy from a branch`로, 브랜치를 `main`, 폴더를 `/ (root)`로 고르고 저장해요.
3. 몇 분 뒤 `https://<사용자 이름>.github.io/<저장소 이름>/` 주소에서 같은 그림 찾기가 열려요.
   주소 끝에 `space/`를 붙이면 은하수 방어선이에요.
