# 같은 그림 찾기

카드를 두 장씩 뒤집어 같은 그림을 찾는 웹 게임이에요. 폰과 컴퓨터 브라우저에서 모두 되고, 로그인 없이 누구나 할 수 있어요.

## 실행하기

게임 전체가 `index.html` 파일 하나에 들어 있어요. 설치할 것 없이 브라우저로 열면 바로 시작돼요.

## 게임 방법

- 난이도: 쉬움(6쌍), 보통(8쌍), 어려움(12쌍)
- 카드를 두 장 뒤집어 같은 그림이면 짝을 찾은 거예요.
- 첫 카드를 뒤집는 순간부터 시간이 흘러요.

| 점수 | |
| --- | --- |
| 짝 맞추기 | +100 |
| 연속 보너스 | 2연속 +50, 3연속 +100, 4연속 +150 … |
| 틀린 시도 | −10 |
| 시간 보너스 | 기준 시간(쉬움 60초 · 보통 90초 · 어려움 150초)에서 남은 1초당 +10 |

## 기록

다 끝낸 게임의 점수는 브라우저 저장소(localStorage)에 남아요. 난이도마다 최고 점수, 가장 빠른 판, 상위 10개 기록을 볼 수 있어요.
기록은 기기와 브라우저마다 따로 저장되고 다른 사람과 공유되지 않아요.

## 인터넷에 올리기 (GitHub Pages)

1. GitHub 저장소의 **Settings → Pages**로 가요.
2. **Source**를 `Deploy from a branch`로, 브랜치를 `main`, 폴더를 `/ (root)`로 고르고 저장해요.
3. 몇 분 뒤 `https://<사용자 이름>.github.io/<저장소 이름>/` 주소로 누구나 들어올 수 있어요.
